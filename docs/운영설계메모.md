# 운영 설계 메모: 재고 경보 봇을 매일 아침 자동으로 돌리기

Google Cloud(GCP) 기준. 설계만 했고 실제 배포는 하지 않았다.

## 요약

- 매일 08:00과 11:00(한국 시간)에 Cloud Scheduler가 Cloud Run Jobs로 봇을 실행한다. 비밀값은 Secret Manager에 둔다.
- 봇이 실패하거나 아예 돌지 않으면 Cloud Monitoring이 운영 채널과 이메일로 알린다.
- 데이터가 늦은 날에는 "안전"이라고 말하지 않는다. 확실한 경보만 보내고 11시에 다시 확인한다.
- 한 달 비용은 보통 1달러 안팎이다.


## 1. 무엇으로 정시에 실행하고, 비밀값은 어디에 두나

| 구성 요소 | 무엇인가 | 하는 일 |
|---|---|---|
| Cloud Scheduler | 정해진 시각에 다른 서비스를 호출하는 예약 서비스 | 매일 08:00과 11:00에 봇을 깨운다 |
| Cloud Run Jobs | 프로그램을 한 번 실행하고 끝나면 꺼지는 서비스 | 봇 프로그램을 실제로 실행한다 |
| Secret Manager | 비밀값 보관함 | API 키와 슬랙 웹훅 주소를 보관한다 |
| Cloud Storage(GCS) | 파일 저장소 | 입력 CSV와 발송 기록을 저장한다 |


## 2. 실패하거나 아예 안 돌았을 때 사람이 어떻게 아나

봇이 죽으면 스스로 알릴 수 없으므로 감시는 봇 바깥(Cloud Monitoring)에서 한다.

| 상황 | 감지 방법 | 알림 받는 곳 |
|---|---|---|
| 봇이 실패로 끝남 | 종료 코드 1 (원인은 `RUN_FAILED` 로그) | 운영 채널 + 이메일 |
| 봇이 아예 안 돎 | 끝날 때마다 남기는 `RUN_FINISHED` 로그가 22시간 동안 없음 | 운영 채널 + 이메일 |
| 끝까지 돌았지만 주의 필요 | 데이터 지연, AI 요약 실패, 키 오류 등의 로그 표식 | 운영 채널 |


## 3. 판매 데이터가 하루 늦게 들어온 날

| 상황 | 08:00 실행 | 11:00 실행 |
|---|---|---|
| 정상 | 슬랙 발송 | 이미 보냈으므로 보내지 않음 |
| 판매·재고 데이터가 하루 늦음 | 경보는 그대로, 안전은 판정 불가로 보냄. "11시에 다시 확인" 안내를 붙임 | 들어왔으면 다시 판정해 "[갱신]" 발송. 여전히 늦으면 운영 채널에만 알림 |
| 입력 파일이 없거나 깨짐 | 실패로 끝남(운영 알림) | 들어왔으면 정상 보고 |

## 4. 한 달 운영 비용

2026-10 공식 가격 페이지 기준 대략치(USD). 하루 2회, 1회 1분 이내 실행을 전제로 했다.

| 항목 | 월 비용 |
|---|---|
| Cloud Run Jobs, Scheduler, Secret Manager | 무료 범위 |
| 저장소, 로그, 알림 | $0~0.05 |
| Claude API (AI 요약) | 보통 $0.2~0.4, 최악 약 $2.6 |
| **합계** | **보통 약 $0.2~0.5, 최악 약 $3** |

최악은 한 달 내내 매일 데이터가 늦어 하루 보고가 2번이고, 보고마다 AI 요약이 검증에 실패해 재요청 2번(호출 3번)이 겹친 경우다.
