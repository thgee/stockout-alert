# AI 도구 사용 메모

## 어디에 AI 도구를 썼는지
- 설계: Claude Code 에이전트 팀(설계·데이터 분석·운영·반론·면접 준비 역할 5개)에게 데이터 이상 후보와 설계 방향을 제안하도록 했습니다. 저는 그 결과를 검토하고 근거를 확인하며 설계 방향을 결정하였습니다.
- 데이터 품질 체크리스트: 데이터 분석 경험이 없어서, "이런 CSV에서 보통 뭐가 잘못되는지"를 AI에게 먼저 물어봤습니다. 채널 표기 통일, 중복 행, 음수 값, 하루 급증, 빈 날 같은 항목은 AI가 제안한 체크리스트였고, 각 항목이 실제로 이 데이터에 있는지는 직접 확인했습니다.
- 구현: Claude Code가 설계서대로 코드와 테스트를 작성했습니다. 구현 단계마다 끊어가며 설계대로 가고있는지 직접 확인했습니다.

## AI 결정중에 직접 고치거나 버린 것
- 미리 정의되지 않은 텍스트(채널, 재고 상태, 창고)는 추측해서 계산에 포함시키지 말고, 담당자에게 알리도록 했습니다. 대소문자나 공백 차이처럼 확실한 부분들만 코드로 고쳐서 계산에 포함시켰습니다.
- AI는 창고간의 물류 이동이 자유롭다고 가정했는데, 저는 창고별로 판매 채널 (국내, 해외) 이 정해져있다고 판단하여, 창고와 채널을 매핑하고 그 그룹마다 독립적으로 계산하도록 수정했습니다.
- 요약에 쓰이는 LLM모델을 claude-sonnet-5으로 결정하였습니다. 이유는 지금까지 여러 모델을 사용해본 경험 상, 3~5문장 요약에 충분하고 비용이 낮다고 판단했기 때문입니다.
